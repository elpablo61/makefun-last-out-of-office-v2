## The line

> My auto-reply used to say 'I will respond within 24 hours.' It now says 'your latte is ready, Marco.'

## How it runs

`main.ts` (node22) writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`). One line, 101 characters, no trailing newline.
